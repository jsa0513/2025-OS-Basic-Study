# Chap15-08 : 파일 시스템 내부구조_NFS
LAN(또는 WAN)을 거쳐 원격 파일에 접근하기 위한 소프트웨어 시스템의 구현과 명세

이질적 환경에서 작동

## 개요
* 서로 연결된 워크스테이션의 집합을 독립적인 파일 시스템을 가진 독립적인 기계들의 집합으로 간주
* 시스템들 사이에서 일정 수준의 공유를 투명하게 허용
  * 사용자가 접근 방식을 몰라도 됨 (로컬 디스크처럼 동작)
* 클라이언트 서버 관계 기반
  * 한 시스템은 동시에 클라이언트이자 서버일 수 있음
* 원격 파일 시스템의 공유는 클라이언트에게만 영향을 줌

특정 시스템 M1이 원격 디렉터리에 접근하는 과정
1. M1이 마운트 명령 수행 -> 원격 디렉터리를 로컬 파일 시스템의 디렉터리 상에 마운트
2. 마운트된 디렉터리가 로컬 파일 시스템의 하부 트리처럼 보임 (기존 하부 트리를 대체)
3. 로컬 디렉터리가 새로 마운트된 디렉터리의 루트의 이름이 됨

### 연속 마운트
* 한 파일 시스템이 원격 마운트된 파일 시스템에 다시 마운트되는 것
* *이행성(transitivity)* 특성을 갖지 않음
* 원격 파일 시스템을 마운트하더라도, 해당 원격 파일 시스템에 이미 마운트되어 있던 다른 파일 시스템에는 접근 불가능

## 마운트 프로토콜
서버 <-> 클라이언트 사이의 초기 논리적 연결을 생성

1. 클라이언트가 서버에게 원격 디렉터리 마운트 요구
2. 서버는 수출 리스트로부터 해당 클라이언트가 접근 가능한 디렉터리인지 확인
3. 허용된 요구일 시, 키(key)로 사용할 파일 핸들 반환
* 파일 핸들은 파일 시스템 식별자와 inode 번호로 구성
* 서버는 클라이언트 시스템+각 시스템에 현재 마운트 된 디렉터리 리스트 유지

## NFS 프로토콜
원격 프로시저가 지원하는 연산
* 디렉터리 내 파일 검색
* 디렉터리 항목 읽기
* 링크와 디렉터리 조작
* 파일 속성 접근
* 파일 읽기와 쓰기

원격으로 마운트 된 디렉터리에 대한 *파일 핸들*이 구축되어야만 프로시저 호출 가능

NFS 서버의 주요 특징: **무상태성(Stateless)**

서버가 클라이언트에 대한 정보를 유지 X -> open, close 연산 생략

서버는 모든 NFS 데이터를 동기적으로 씀으로써 데이터 유실 방지
* 성능 문제 -> 빠르고 비휘발성인 캐시를 갖는 저장장치를 사용해 해결

하나의 NFS 쓰기 프로시저 호출은 원자성(atomic)이 보장

병행성 제어 기법 제공 X

쓰기 시스템 콜은 용량의 제한 때문에 여러 개의 RPC 쓰기로 분리될 수 있음
* 같은 원격 파일에 쓰기를 하는 두 사용자의 데이터가 뒤섞일 수 있음
* 상태성(stateful)인 록(lock) 제공 또는 NFS와는 별도의 적절한 기법을 사용하여 해결

NFS는 가상 파일 시스템(VFS)을 통하여 운영체제로 통합됨

### Stateful vs Stateless
**Stateful**
* 서버가 클라이언트의 상태 보존
* 클라이언트 상태를 가지므로 용량 한계 O
> 로그인 유지, 쿠키 저장, 세션 메모리 유지 등

**Stateless**
* 서버가 클라이언트의 상태 보존 X
* 클라이언트가 매 요구마다 매개변수들의 완전한 집합을 제공해야 함
* 요청 -> 응답만 수행
* 대량의 트래픽이 발생해 서버 확장이 필요할 때에도 대처가 쉬움

## 경로 이름 변환
1. 경로를 각 디렉터리 이름으로 나눔
2. 각 컴포넌트마다 NFS 룩업(lookup) 호출을 수행해서 서버와 통신
3. 경로 중간에 다른 파일 시스템이 마운트 되어 있다면, 그 이후의 컴포넌트를 처리하기 위해 별도의 RPC(Remote Procedure Call)를 유발

-> 이러한 과정은 각 클라이언트의 논리적 이름 공간이 다르기 때문에 필요

룩업을 빠르게 하기 위해 클라이언트 측 디렉터리 이름 룩업 캐시 사용

-> 시작 부분의 경로 이름이 같은 파일들의 참조 속도를 증가시킴

앞서 보았던 이미 마운트 된 원격 파일 시스템에 다시 또 하나의 원격 파일 시스템을 마운트하는 연속 마운트의 경우, 경로 이름 순회 시 하나 이상의 서버가 연관될 수 있음.
이 때는 마운트 된 디렉터리가 아닌 원래 서버의 디렉터리를 보게 됨.
