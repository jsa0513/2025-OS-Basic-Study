# Chap13-04 : 파일 시스템 인터페이스_보호

## 접근의 유형
1. 읽기
2. 쓰기
3. 실행
4. 추가 - 파일의 끝에 새로운 정보 첨부
5. 삭제
6. 리스트 - 파일의 속성, 이름 등을 출력
7. 속성 변경

## 접근 제어
### ACL
각 파일과 디렉터리에 접근 제어 리스트(ACL)를 연관 -> 세밀한 권한 관리 가능
> setfacl, getfacl과 같은 별도의 명령어 사용

### 허가
접근 리스트 간소화 -> 사용자를 소유자, 그룹, 일반인으로 분류
> ex. -rwxrwxr-x
> * 세 개의 필드는 소유자, 그룹, 일반인을 나타냄
> * r, w, x는 각각 읽기, 쓰기, 실행 권한을 나타냄
> * 소유자(파일 생성자) - rwx 가능, 그룹 - rwx 가능, 일반인 - rx 가능

허가와 ACL이 상충할 때는 일반적으로 명시적으로 부여된 권한인 *ACL을 부여*
