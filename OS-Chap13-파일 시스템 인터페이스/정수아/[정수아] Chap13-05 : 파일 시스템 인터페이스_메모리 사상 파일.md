# Chap13-05 : 파일 시스템 인터페이스_메모리 사상 파일
파일 시스템 콜을 매번 사용하는 대신 *메모리 참조 방식*을 사용하는 접근 방식

## 기본 기법
1. 일부 페이지를 디스크에 있는 파일의 블록에 사상
2. 이후에는 read(), write() 등 시스템 콜(오버헤드) X -> 메모리를 통해 파일 조작

메모리 매핑된 파일에 대한 쓰기는 동기식

### 동기식 vs 비동기식
동기식
* 해당 요청의 응답을 받아야 다음 동작을 실행(직렬)
비동기식
* 요청을 보낸 후 응답과 관계 없이 다음 동작 실행(병렬)
