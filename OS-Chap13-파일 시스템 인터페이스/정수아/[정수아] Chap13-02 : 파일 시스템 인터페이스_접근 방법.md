# Chap13-02 : 파일 시스템 인터페이스_접근 방법

## 순차 접근
맨 앞부터 순차적으로 접근

읽거나 쓸 때, 현재 위치를 추적하는 파일 포인터(offset)가 자동으로 증가

오프셋을 맨 앞/뒤로, n개의 레코드만큼 앞/뒤로도 이동 가능

## 직접 접근(상대 접근)
파일은 고정 길이의 논리 레코드의 집합으로 정의

디스크 모델에 기반 -> 디스크가 임의의 파일 블록에 임의적 접근을 허용하기 때문

읽기/쓰기 순서에 제약 X

파일 연산 시 블록 번호 파라미터를 포함해야 함
> 이때 블록 번호는 상대 블록 번호로, 파일의 물리적 저장 위치와 관계 X

* 논리적 레코드의 길이가 L일 때, N번째 레코드에 대한 요청

-> 파일의 L * (N)의 위치로부터 L byte

## 순차 접근 vs 직접 접근
직접 접근 파일이 있으면 순차 파일 기능을 쉽게 제공 가능

반면, 순차 접근 파일에서 직접 접근을 흉내 내는 것은 비효율적
