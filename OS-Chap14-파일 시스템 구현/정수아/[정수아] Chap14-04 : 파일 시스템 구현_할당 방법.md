# 🐾Chap14-04 : 파일 시스템 구현_할당 방법
파일들을 어떻게 저장장치 공간에 배치할 것인지?

-> 디스크 공간을 효율적으로 사용하고, 파일들을 빨리 접근할 수 있도록

저장장치 공간 할당 방법: 연속, 연결, 색인(index) 기법

## 🐾연속 할당
각 파일이 저장장치 내에서 연속적인 공간을 차지하도록

-> 논리적으로 근접한 블록이 물리적으로도 근접하다면, 디스크 탐색의 횟수를 최소화

첫 번째 블록의 주소와 (블록 단위의) 길이만 있으면 됨

-> n 블록 길이의 파일이 블록 b에서 시작한다면, b부터 b+n-1까지를 차지

![image](https://github.com/user-attachments/assets/7c8a3e3c-4c47-4850-9fd3-875dcc6c2a68)

장점
* 순차 접근, 직접 접근 모두 지원 가능

단점
* 새로운 파일을 위한 가용 공간을 찾을 때 문제 발생
  * 실행 단계에서 공간을 할당하는 동적 공간 할당 문제
  * 파일의 크기나 위치가 고정되어 있지 않아, 가용 공간 관리와 관련된 문제가 자주 발생
  * 일반적으로 최초, 최적 적합 적용(최악 적합보다 효율적)
  * 외부 단편화 문제 -> 주기적 밀집 작업으로 해결, 많은 시간과 비용 소모
* 실행 과정에서 만들어질 파일의 크기를 예측하기 힘듦
  * 너무 작은 공간을 예약하면 파일이 커질 수 없음
  * 필요한 공간을 지나치게 크게 추정하면 공간의 낭비(내부 단편화)
  * 어느 정도의 연속된 공간만 초기에 할당하고, 추후 n개의 연속된 공간을 단위로 할당하는 방식 사용 가능
